## Daniel Cross 참고 공개 홈페이지 UI 개편

- 공개 홈페이지를 따뜻한 중성 배경과 고정 워크스페이스 사이드바 중심의 레이아웃으로 바꿨다.

## 미니멀 공개 UI 2차 정리

### 한 일
- 홈의 우주 캔버스, 별 장식, Cosmos 스크립트 로딩과 전용 키보드 라우팅을 제거했다.
- 왼쪽 사이드바의 `Current focus` 카드와 `Find me` 라벨을 제거하고 이메일·GitHub 링크는 하단에 유지했다.
- 비어 있는 히어로·연락처 설명은 대체 문구를 강제로 표시하지 않고 숨기도록 바꿨다.
- 기존 우주 테마 CSS가 공개 섹션 제목과 빈 상태 문구를 밝은색으로 덮던 충돌을 수정했다.
- 홈과 섹션 간격, 카드 높이, 모바일 상단 바 safe-area와 메뉴 overscroll을 조정했다.
- 모바일 메뉴를 열면 첫 메뉴로 포커스를 옮기고 본문을 `inert` 처리한 뒤 닫을 때 복원하도록 보완했다.
- 저장된 Moment가 0개여도 사이드바 `Moments` 메뉴는 항상 보이게 하고, 빈 페이지에는 간결한 상태 문구를 표시했다.
- 독립 Portfolio·Study·Moments 페이지의 최상위 제목을 `h1`으로 바로잡고 관리자 검색 입력의 접근 가능한 이름을 보완했다.

## 공개·관리자 UI 통합 개선

### 한 일
- 왼쪽 사이드바의 `personal page` 상태 행을 DOM과 렌더링 코드에서 제거하고 기존 메뉴 위치는 여백으로 유지했다.
- 공개 본문 폭과 Hero·섹션 간격을 다듬고, 섹션 제목의 구분선과 이미지 없는 프로젝트 행 높이를 정리했다.
- 기존 다단 레이아웃 규칙이 Portfolio 목록을 가로로 밀어내던 충돌을 해소해 모든 뷰포트에서 1열 목록을 유지했다.
- 관리자 전용 `assets/admin.css`를 추가해 공개 화면과 같은 warm gray, IBM Plex Sans KR, 평면형 표면·구분선 체계로 통일했다.
- 관리자 콘텐츠 목록의 중첩 버튼을 형제 버튼 구조로 바꾸고 List/Table/Gallery/Board가 좁은 사이드바 안에서 겹치지 않게 정리했다.
- 모바일 관리자 속성을 2열로 압축하고 저장 동작을 하단 action dock으로 고정했으며, 페이지 drawer에 backdrop·닫힌 메뉴와 열린 상태 본문의 `inert`·스크롤 잠금·Escape 닫기·포커스 복귀를 적용했다.
- 제목 누락 오류를 실제 편집 제목에 표시하고 저장 상태를 `변경사항 있음`, `저장 중…`, `임시저장됨`, `게시됨`으로 통일했다.
- 미리보기·기록의 선택 상태와 Undo/Redo 비활성 상태를 노출하고 contenteditable의 역할·이름·spellcheck를 보완했다.
- 공개 화면에서 쓰지 않는 연락 안내 문구 편집을 제거하고 관리자 패널을 실제 노출 위치에 맞는 `사이드바 연락처`로 정리했다.
